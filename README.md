# secondhand-sync

번개장터에 올린 상품을 중고나라에도 똑같이 올려 주는 개인용 도구입니다.

중고 물건을 두 군데에 올리려면 같은 사진과 설명을 두 번 입력해야 합니다.
이 도구는 **번개장터를 기준으로 삼아** 중고나라 쪽을 맞춰 줍니다.
사람이 하는 것처럼 실제 웹 화면을 열어서 클릭하고 입력하는 방식이라,
특별한 권한이나 비공개 연동 없이 내 계정으로 직접 동작합니다.

## 무엇을 해 주나요

- 번개장터에만 있는 상품을 **중고나라에 새로 올립니다** (사진·제목·설명·가격 포함)
- 번개장터에서 제목이나 가격을 고치면 **중고나라 글도 똑같이 고칩니다**
- 번개장터에서 판매 완료하면 **중고나라도 판매 완료로 바꿉니다**
- 한쪽에서 상품을 숨기면 **반대쪽도 숨깁니다** (양방향)

## 무엇을 하지 않나요

안심하고 쓰실 수 있도록, 아래 일은 **절대 하지 않습니다.**

- 상품을 삭제하지 않습니다.
- 숨긴 상품을 마음대로 다시 꺼내지 않습니다.
- 로그인 비밀번호나 인증번호를 묻거나 저장하지 않습니다. 로그인은 직접 하십니다.
- 바꿀 내용을 먼저 보여 드리고, **확인하기 전에는 아무것도 건드리지 않습니다.**
- 미리 짝지어 둔 상품만 고칩니다. 제목이 비슷하다고 알아서 같은 상품으로 취급하지 않습니다.

## 준비물

1. **Node.js** 22.18 이상 (24 이상 권장) — [nodejs.org](https://nodejs.org)에서 내려받아 설치
2. **Google Chrome**
3. 번개장터 계정과 중고나라 계정

설치는 터미널에서 이 폴더로 이동한 뒤 한 번만 하면 됩니다.

```sh
npm install
```

## 쓰는 순서

### 1단계 — 로그인 (처음 한 번)

```sh
npm run browser
```

새 크롬 창이 열립니다. 번개장터 탭과 중고나라 탭에서 **직접 로그인**하세요.
중고나라는 로그인할 때 **"로그인 유지하기"를 켜 두면** 한동안 다시 로그인하지 않아도 됩니다.

> 이 창은 평소 쓰는 크롬과 분리된 전용 창입니다. 원래 크롬의 로그인에는 영향을 주지 않습니다.

로그인이 끝나면 창을 닫고, 내 계정을 기준으로 등록해 둡니다.

```sh
npm run whoami -- --save
```

이렇게 해 두면 **나중에 다른 계정으로 로그인된 상태에서는 아예 실행되지 않습니다.**
남의 상점을 건드리는 사고를 막기 위한 안전장치입니다.

### 2단계 — 양쪽 상품 읽어 오기

```sh
npm run collect
```

크롬 창이 열려 번개장터와 중고나라를 차례로 훑습니다. 상품 수에 따라 몇 분 걸립니다.
사진도 함께 내려받습니다. **이 단계는 아무것도 바꾸지 않습니다.**

### 3단계 — 무엇이 바뀔지 확인하기

```sh
npm run plan
```

이런 식으로 보여 줍니다.

```
번개장터 13건 / 중고나라 14건 / 연결 10건
등록 2 · 수정 1 · 판매완료 0 · 중고나라숨김 0 · 번개장터숨김 0 · 연결후보 1

[등록 예정] 중고나라에 새로 올립니다.
  - 아크네스튜디오 트윌자켓 블랙 (130,000원) 번개장터 441377039

[수정 예정] 연결된 상품만 수정합니다.
  - 중고나라 233338324 "TRIPLE8 헬멧" (가격 55,000원 → 50,000원)

[연결 후보] 자동 연결하지 않습니다.
  - 번개장터 441239580 "인라인헬멧 TRIPLE8 ..." (50,000원)
      ↔ 중고나라 233338324 "TRIPLE8 ... 헬멧" (50,000원, 유사도 0.5, 같은 가격)
```

**여기서도 아직 아무것도 바뀌지 않았습니다.** 계획만 보여 주는 단계입니다.

### 4단계 — 같은 상품 짝지어 주기 (필요할 때만)

두 사이트에 이미 올려 둔 같은 상품인데 제목이 조금 달라서 도구가 확신하지 못하면
**"연결 후보"**로 보여 줍니다. 맞다면 두 상품 번호를 알려 주세요.

```sh
npm run link -- --bunjang 441239580 --joongna 233338324
```

한 번 짝지어 두면 다음부터는 기억합니다. 짝을 지어야만 수정·판매완료가 반영됩니다.
잘못 연결했다면 `npm run link -- --remove --bunjang 441239580`으로 풀 수 있습니다.

### 5단계 — 실제로 반영하기

계획을 확인하셨으면 실행합니다.

```sh
npm run apply -- --confirm
```

`--confirm`을 빼면 **아무 일도 일어나지 않습니다.** 실수로 실행되는 걸 막기 위한 장치입니다.

한 건만 시험해 보고 싶다면:

```sh
npm run apply -- --confirm --only create --limit 1   # 등록 1건만
npm run apply -- --dry-run                           # 입력만 해 보고 저장은 안 함
```

끝나면 2단계와 3단계를 다시 돌려서 제대로 반영됐는지 확인하시면 됩니다.

## 자주 생기는 일

**"로그인이 필요합니다"라고 나와요**
중고나라 로그인은 생각보다 자주 풀립니다. `npm run browser`로 다시 로그인하고,
이번엔 **"로그인 유지하기"**를 꼭 켜 주세요.

**"계정이 다릅니다"라고 멈춰요**
등록해 둔 계정과 지금 로그인된 계정이 다릅니다. 의도한 것이라면
`npm run whoami -- --save`로 기준 계정을 다시 등록하세요.

**"카테고리 매핑이 없습니다"라며 건너뛰어요**
중고나라는 카테고리를 반드시 골라야 등록됩니다. 번개장터 카테고리와 중고나라 카테고리의
짝을 `config.json`의 `categoryMap`에 한 줄 추가해 주세요. 건너뛴 상품의 번호를 함께 알려 줍니다.

```json
"categoryMap": {
  "320300400": "패션의류 > 남성의류 > 자켓/코트"
}
```

**"계획이 N분 전 것입니다"라고 거부해요**
오래된 계획으로 반영하면 그 사이 바뀐 내용을 덮어쓸 수 있어 1시간이 지나면 막습니다.
`npm run collect` → `npm run plan`을 다시 실행하세요.

**중간에 멈췄어요**
추가 인증 화면이 뜨면 스스로 처리하지 않고 멈춥니다. 직접 인증한 뒤 다시 실행하세요.
이미 반영된 건 다시 하지 않습니다.

## 내 정보는 어디에 저장되나요

로그인 정보, 수집한 상품 목록, 내려받은 사진은 전부 이 폴더 안
`.local/` 아래에만 저장되고 **Git에는 올라가지 않습니다.** 외부로 전송하지 않습니다.

| 위치 | 내용 |
|------|------|
| `.local/browser-profile/` | 전용 크롬 로그인 세션 |
| `.local/data/snapshot.json` | 마지막으로 읽어 온 양쪽 상품 목록 |
| `.local/data/images/` | 중고나라에 올릴 사진 |
| `.local/data/links.json` | 짝지어 둔 상품 번호 |
| `.local/data/plan.json` | 마지막 변경 계획 |
| `.local/data/apply-log.json` | 마지막 반영 결과 |
| `.local/data/account.json` | 실행을 허용할 계정 이름 |

## 설정 바꾸기 (config.json)

| 항목 | 설명 |
|------|------|
| `sync.title` / `sync.price` / `sync.description` | 제목·가격·설명 중 무엇을 맞출지 (`false`면 건드리지 않음) |
| `sync.hideSource` | 중고나라에서 숨긴 상품을 번개장터에서도 숨길지 |
| `joongna.condition` | 상품 상태 `used`(중고) 또는 `new`(새상품) |
| `joongna.components` | 구성품 `none` / `partial` / `full` |
| `joongna.freeShipping` | 무료배송으로 올릴지 |
| `categoryMap` | 번개장터 카테고리 → 중고나라 카테고리 짝 |

## 개발자용 메모

TypeScript로 작성했고, Node가 타입을 그대로 벗겨 실행하므로 **빌드 단계가 없습니다.**
타입만 확인하려면 `npm run typecheck`.

```
src/
  browser.ts collect.ts plan.ts link.ts apply.ts whoami.ts   명령 하나당 파일 하나
  lib/
    types.ts       도메인 타입과 어댑터 규약
    config.ts      설정·경로·기본값
    store.ts       .local/data JSON 입출력
    session.ts     브라우저 프로필, 로그인 확인, 열고-닫기
    account.ts     실행 허용 계정 확인
    product.ts     상품 정규화
    match.ts       연결 후보 유사도
    links.ts       연결 정보
    diff.ts        변경 계획 계산
    actions.ts     계획을 실제 조작으로 옮기는 핸들러
    report.ts      사람이 읽는 출력
    platforms/
      bunjang.ts   번개장터 화면 지식
      joongna.ts   중고나라 화면 지식
      index.ts     두 구현이 규약을 지키는지 확인하고 골라준다
```

지키면 좋은 규칙:

- 선택자와 URL은 `platforms/` 안에만 둔다. 다른 파일은 화면을 모른다.
- 계획(`diff.ts`)과 반영(`actions.ts`)을 나눈다. 계획은 브라우저 없이 계산·검증할 수 있다.
- 새 작업은 `types.ts`의 `ActionType`에 이름을 더하고 `actions.ts` 핸들러 표에 한 줄을 더한다.
  `apply.ts`에는 분기를 넣지 않는다.
- 기본값은 `config.ts` 한곳에서만 채운다.

### 확인한 화면 구조

- 번개장터 상품관리: `role="row"` 표, 열은 `_col-name` / `_col-price` / `_col-saleStatus` / `_col-imageUrl`.
  **"전체"(`tab=ALL`) 탭에는 숨긴 상품이 나오지 않는다.** 숨긴 상품은 `tab=HIDDEN`에서 읽고,
  그 탭의 판매상태 칸은 판매중으로 보이므로 탭 기준으로 숨김을 판단한다.
  숨김은 행의 `상품숨김` 버튼이 확인창 없이 바로 적용되고, 해제는 `tab=HIDDEN`의 `숨김해제` 버튼이다.
- 번개장터 상세: `ul[aria-label="상품 카테고리"]`에서 카테고리, `img[src*="/product/<ID>_"]`에서 사진.
- 번개장터 수정 화면: `input[name="common.name"]`, 상품 설명 textarea에서 전체 제목·설명·가격.
- 중고나라 내 상점: `a[href^="/product/"]` 카드, 카드 문구로 판매완료·숨겨진 상품·예약중 판단.
- 중고나라 관리 시트: `button[aria-label*="관리 옵션"]` → `role="option"`
  (배송신청·상품수정·상태변경·상품삭제), 상태변경 안에 예약중·상품 숨김·판매완료.
- 중고나라 등록/수정 폼: `/product/form?type=regist`, `/product/form?type=modify&productSeq=<ID>`,
  `#product-name`, `#product-description`, 상품상태 `#used`/`#new`, 구성품 `#none`/`#partial`/`#full`.
  판매가격은 `#productPrice`가 읽기 전용이라 눌러서 열리는 "판매가 설정" 패널에서 입력한다.
- 제목 비교는 연속 공백을 하나로 줄여서 맞춘다. 중고나라가 저장할 때 공백을 줄이기 때문이다.

선택자는 두 사이트 배포에 따라 바뀔 수 있다. 수집 건수가 0이거나 폼을 찾지 못하면 화면 구조를 먼저 확인한다.
